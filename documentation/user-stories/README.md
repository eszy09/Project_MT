# User Stories

User stories define user value. Acceptance criteria define observable completion.

## Story format

```text
As a <user>,
I want <capability>,
so that <outcome>.
```

## Priority

- P0: required for the first durable end-to-end milestone
- P1: required for V1
- P2: later enhancement
