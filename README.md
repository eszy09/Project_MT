# Project_MT

Project_MT is a fitness application that makes transformation tracking more intuitive through reliable set-by-set workout logging, progress tracking, explainable guidance, and interactive 3D body models.

## Current status

The repository is in planning and foundation setup. Product and architecture decisions requiring owner approval are recorded before application scaffolding begins.

## Initial delivery target

A user must be able to create an account, complete onboarding, log a set-by-set workout, restart the system, sign back in, and retrieve exactly the same data.
